# 가계부 새 기록 버튼 FAB 전환 + 더블탭 수정

## 대상 파일
`frontend/src/app/pages/HouseholdPage.tsx`

---

## 수정 1: 헤더에서 "+ 새 기록" 버튼 제거

아래 코드를 찾아 **button 태그 전체 삭제**

```tsx
// 삭제 대상
<button
  onClick={() => navigate('/record', { state: { format: 'HARU가계부', from: '/household' } })}
  style={{ marginLeft: 'auto', background: '#166534', color: '#fff', border: 'none', borderRadius: 8, padding: '6px 14px', fontWeight: 600, fontSize: 14, cursor: 'pointer' }}
>
  + 새 기록
</button>
```

헤더 div는 아래처럼 버튼 없이 유지:

```tsx
<div style={{ background: '#fff', borderBottom: '1px solid #e5e7eb', padding: '12px 16px', display: 'flex', alignItems: 'center', gap: 8 }}>
  <button
    onClick={() => navigate(-1)}
    style={{ background: 'none', border: 'none', fontSize: 22, cursor: 'pointer', padding: '0 4px', color: '#374151' }}
  >
    ←
  </button>
  <span style={{ fontWeight: 700, fontSize: 18, color: '#166534' }}>HARU가계부</span>
</div>
```

## 수정 2: FAB 버튼 추가 (최하단, 모달 바로 위)

`{/* 예산 설정 모달 */}` 블록 **바로 위**에 아래 FAB 코드를 삽입:

```tsx
{/* FAB — 새 기록 */}
<button
  onPointerDown={() => navigate('/record', { state: { format: 'HARU가계부', from: '/household' } })}
  style={{
    position: 'fixed',
    bottom: 88,
    right: 20,
    width: 56,
    height: 56,
    borderRadius: '50%',
    background: '#166534',
    color: '#fff',
    border: 'none',
    boxShadow: '0 4px 14px rgba(22,101,52,0.45)',
    fontSize: 28,
    fontWeight: 700,
    cursor: 'pointer',
    display: 'flex',
    alignItems: 'center',
    justifyContent: 'center',
    zIndex: 900,
    touchAction: 'manipulation',
    WebkitTapHighlightColor: 'transparent',
  }}
  aria-label="새 기록 추가"
>
  +
</button>
```

### 포인트 설명
- `onPointerDown`: 모바일 첫 탭부터 즉시 반응 (onClick 더블탭 문제 해결)
- `touchAction: 'manipulation'`: 브라우저 더블탭 줌 방지
- `WebkitTapHighlightColor: 'transparent'`: iOS 탭 깜빡임 제거
- `bottom: 88`: 하단 네비게이션 바(약 68px) 위에 여유 있게 위치
- `zIndex: 900`: 모달(1000) 아래, 일반 콘텐츠 위

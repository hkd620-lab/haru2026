# CC 지시서 — TTS 모델 tts-1로 통일

## 작업 개요

OpenAI TTS 모델을 `tts-1`로 통일해줘.
일부 코드에 `tts-1-hd`가 섞여있을 수 있는데 모두 `tts-1`로 맞추는 작업이야.
비용 절감이 목적 (tts-1-hd는 2배 비용).

## 작업 전 안전 저장

```bash
cd ~/HARU2026 && git add -A && git commit -m "작업 전 안전 저장 - TTS 모델 tts-1 통일" --allow-empty
```

## 1단계 — 현황 파악 (먼저 확인만)

전체 코드베이스에서 TTS 관련 모델명 사용 위치를 찾아줘:

```bash
grep -rn "tts-1\|tts-1-hd" ~/HARU2026/functions/src/ ~/HARU2026/frontend/src/
```

확인할 사항:
- functions/src/index.ts의 generateTTS 함수
- 그 외 다른 위치에 tts 모델 지정 있는지

## 2단계 — 통일 작업

`tts-1-hd`로 되어있는 곳을 모두 `tts-1`로 변경.
`tts-1`로 이미 되어있으면 그대로 두기.

⚠️ 주의: voice 설정(nova 등)은 절대 건드리지 말 것. 모델명만 변경.

## 3단계 — 빌드 확인

```bash
cd ~/HARU2026/functions && npm run build
```

## 보고 형식

1. tts-1-hd 사용 위치 (파일/줄)
2. tts-1 사용 위치 (파일/줄)
3. 변경한 줄 + 전후 코드
4. 빌드 결과
5. 배포 대기 중

## ⚠️ 절대 금지

- voice 설정 변경 금지
- 다른 함수 임의 수정 금지
- 배포 절대 금지 (대표님 승인 후)

# CC 지시서 — GPT-4o 일기학습 하이브리드 적용

## 작업 개요

영어일기학습의 문법 분석에서 GPT-4o를 조건부로 사용하도록 수정.
- 짧은 일기 (200자 이하): Gemini만 사용 (빠르고 싸게)
- 긴 일기 (200자 초과): Gemini + GPT-4o (정확하게)

영어성경은 절대 건드리지 말 것 (캐시 효율 100%로 유지).

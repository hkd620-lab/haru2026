# CC 지시서 — 뉴스 메뉴 숨김 + /news 라우트 가드 (오늘 3·4단계 통합)

## 작업 개요

뉴스 기능을 일반 사용자에게 완전히 숨기는 작업이야.
현재 백엔드는 막혀있지만(어제 작업), 프론트엔드 메뉴와 라우트는 노출 상태야.

목표:
1. HomePage의 "최신외신 3편" 버튼 → 개발자에게만 보이게
2. /news 라우트 → 비개발자가 URL 직접 입력해도 차단

## 작업 전 안전 저장

```bash
cd ~/HARU2026 && git add -A && git commit -m "작업 전 안전 저장 - 뉴스 메뉴 숨김 + 라우트 가드" --allow-empty
```

## 1단계 — HomePage 뉴스 버튼 숨김

### 파일: `~/HARU2026/frontend/src/app/pages/HomePage.tsx`

현재 BUTTONS 배열에 "최신외신 3편" 버튼이 들어있어. devOnly 플래그가 적용 안 된 상태야.

수정 방법:
- BUTTONS 배열에서 "최신외신 3편" 항목에 `devOnly: true` 플래그 추가
- 만약 BUTTONS 배열이 devOnly 필터링을 안 한다면, TABS 처럼 필터 로직 추가
- TABS의 "햅스튜디오"가 devOnly로 처리되는 패턴을 그대로 따라줘 (기존 코드 스타일 유지)

⚠️ 주의: 다른 버튼들은 절대 건드리지 말 것.

## 2단계 — /news 라우트 가드

### 파일: `~/HARU2026/frontend/src/app/pages/NewsPage.tsx`

NewsPage 컴포넌트 최상단에 개발자 UID 체크 추가:
- 개발자 UID: `naver_lGu8c7z0B13JzA5ZCn_sTu4fD7VcN3dydtnt0t5PZ-8`
- 비개발자 접근 시 `useEffect`에서 즉시 `navigate('/')`로 리다이렉트
- 패턴은 `AdminChecklistPage.tsx`의 가드 방식을 참고해서 동일하게 적용

기존 import에 `useNavigate`가 없으면 추가하고, `useEffect`도 필요하면 추가.
auth는 이미 import되어 있을 가능성 높으니 확인 후 사용.

⚠️ 주의: NewsPage의 다른 로직(뉴스 표시, 새로고침 버튼 등)은 그대로 둘 것.

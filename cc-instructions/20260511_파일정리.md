### 2단계: `_zombie_backup_20260428/` 폴더 삭제

```bash
# 2-A: 폴더 존재 확인
```

### 5단계: macOS Finder 중복 복제 파일 삭제 ⚠️ 가장 위험

이 단계는 **반드시 한 파일씩 import 검증 후 삭제**한다.

```bash
# 5-A: 중복 복제 파일 목록 추출 (공백+숫자 패턴: " 2.tsx", " 3.tsx" 등)
cd ~/HARU2026 && find frontend/src -type f \( -name "* [0-9].tsx" -o -name "* [0-9].ts" -o -name "* [0-9].jsx" -o -name "* [0-9].js" \) | sort > /tmp/haru_duplicate_candidates.txt
cat /tmp/haru_duplicate_candidates.txt
wc -l /tmp/haru_duplicate_candidates.txt

# 5-B: 각 파일별 import 검증 후 안전한 것만 삭제
cd ~/HARU2026 && while IFS= read -r filepath; do
  filename=$(basename "$filepath")
  # 파일명에서 " 2", " 3" 등 제거하고 확장자도 제거한 base name
  base=$(echo "$filename" | sed -E 's/ [0-9]+\.(tsx|ts|jsx|js)$//')
  # 전체 src에서 이 base name을 import하는 코드가 있는지 확인
  # (단, 자기 자신 파일은 제외)
  import_count=$(grep -r "$base" frontend/src/ --include="*.tsx" --include="*.ts" --include="*.jsx" --include="*.js" 2>/dev/null | grep -v "$filepath" | grep -E "(import|from)" | wc -l)
  
  if [ "$import_count" -eq 0 ]; then
    echo "🗑️  삭제: $filepath (import 0건)"
    rm "$filepath"
  else
    echo "⚠️  보존: $filepath (base='$base' import $import_count건)"
  fi
done < /tmp/haru_duplicate_candidates.txt

# 5-C: 빌드 확인
cd ~/HARU2026/frontend && npm run build 2>&1 | tail -30

# 5-D: 커밋
cd ~/HARU2026 && git add -A && git commit -m "정리 5단계: macOS 중복 복제 파일 삭제 (import 검증 통과분)"
```

**중단 조건:** 
- 5-C 빌드 실패 시 `git reset --hard HEAD~1`로 복원하고 보고
- 보존 결정된 파일이 5개 이상이면 보고 후 허 교장님 판단 대기

# 🐍 Playwright 자동화 스크립트

위 셀렉터를 그대로 쓸 수 있는 스크립트. 데스크톱 1440×900 기준.

```javascript
// capture-haru-cuts.js
import { chromium } from 'playwright';

const URL = 'https://haru2026-8abb8.web.app/';
const cuts = [
  { name: '01_grape',         selector: '.grape-animation-container',                wait: 4000 },
  { name: '02_hero',          selector: '.hero-section',                              wait: 1000 },
  { name: '03_brain_science', selector: '.next-section-after-hero',                   wait: 600 },
  { name: '04_formats',       selector: '.format-grid',                               wait: 600 },
  { name: '05_sayu',          selector: '.lp-page > section:nth-of-type(4)',          wait: 600 },
  { name: '06_agents',        selector: '.agents-8',                                  wait: 600 },
  { name: '07_pricing',       selector: '.lp-page > section:nth-of-type(7)',          wait: 600 },
  { name: '08_cta',           selector: '.lp-cta',                                    wait: 600 },
];

(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage({ viewport: { width: 1440, height: 900 } });
  await page.goto(URL, { waitUntil: 'networkidle' });

  for (const cut of cuts) {
    const el = await page.locator(cut.selector).first();
    await el.scrollIntoViewIfNeeded();
    await page.waitForTimeout(cut.wait);
    await el.screenshot({ path: `out/${cut.name}.png` });
  }

  // CUT 6: 8개 비서 카드 개별 클로즈업
  for (let i = 1; i <= 8; i++) {
    const card = page.locator(`.agents-8 > div:nth-child(${i})`);
    await card.scrollIntoViewIfNeeded();
    await page.waitForTimeout(300);
    await card.screenshot({ path: `out/06_agent_${String(i).padStart(2,'0')}.png` });
  }

  await browser.close();
})();
```

## 비디오 녹화 모드 (CUT 1용)

GrapeAnimation은 정적 PNG가 아닌 모션이 필요하므로 비디오 녹화:

```javascript
import { chromium } from 'playwright';

const browser = await chromium.launch();
const context = await browser.newContext({
  viewport: { width: 1440, height: 900 },
  recordVideo: { dir: 'videos/', size: { width: 1440, height: 900 } },
});
const page = await context.newPage();
await page.goto('https://haru2026-8abb8.web.app/');
await page.waitForTimeout(5000); // 5초 녹화 (포도송이 + HARU 글자 + 서브타이틀)
await context.close();
await browser.close();
// videos/ 폴더에 webm 생성됨 → ffmpeg로 mp4 변환
```

# ⚠️ 영상 편집 시 주의사항

1. **CUT 1의 GrapeAnimation은 스크린레코딩 필수** — 정적 PNG가 아닌 MP4/GIF 캡처. Playwright video 모드 사용.

2. **AI 비서 텍스트 줄바꿈** — 카드별 sub 텍스트가 폰트사이즈 13px·lineHeight 1.7로 4–5줄로 늘어나는 카드 있음 (T58 하루LAW가 가장 김). 캡처 시 카드 높이가 일정하지 않을 수 있어 그리드 풀샷 캡처 권장.

3. **반응형** — `.format-grid`와 `.agents-8`은 뷰포트별로 컬럼 수가 달라짐:
   - ≤640px: 2열
   - 641–1024px: agents-8=2열, format-grid=5열
   - ≥1025px: agents-8=4열, format-grid=5열

4. **`.lp-page` 루트 확인** — LandingPage L82의 root div className. 모든 nth-of-type 셀렉터는 이 컨테이너 기준.

5. **HARU 글자 애니메이션 타이밍** — opacity·y 애니: delay 1.0s + stagger 0.1s. 서브타이틀: delay 2.5s. 첫 단어 강조: delay 3.0s. 4초 컷 안에 모든 등장이 완료되도록 대기 시간 조정.

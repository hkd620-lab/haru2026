# HARU예언 Gemini 프롬프트 (확정)

## 명칭
- **HARU예언** (구 "나도작가"에서 변경 확정)
- 마케팅: "사주보다 정확한 AI 예언", "과학적 사주, HARU예언"

## 기본 사양

| 항목 | 값 |
|---|---|
| 시놉시스 분량 | 800~1,200자 |
| 이야기 분량 | 5페이지 (4,000~6,000자) |
| 사용 한도 | 월 30회 / 일 1회 |
| 저장 | 없음 (PDF 다운로드만) |

## 5대 법칙 + 보편 원리

### 5대 법칙
| # | 법칙 | 내용 |
|---|---|---|
| ① | 노력 보존 | 열역학 1법칙 — 노력은 사라지지 않음 |
| ② | 쇠함 | 열역학 2법칙 — 늙음, 연약함 |
| ③ | 행위 보응 | 준 것보다 적게 받음 |
| ④ | 불운 | 대부분 내 탓 (천재지변 제외) |
| ⑤ | 관계 | 좋아하는 사람과 미워하는 사람 공존 |

### 보편 원리 (추가)
- 권력 고독
- 사랑 300일
- 유전 대물림
- 습관 운명
- 유유상종

## 작성 규칙

✅ **반드시**:
- 이야기로 자연스럽게 표현
- 마지막은 희망적으로
- 독자가 "내 이야기 같다" 느끼게

❌ **절대 금지**:
- 5대 법칙 직접 언급 금지
- 교훈조 금지

## 3가지 예언 종류

1. **나의 미래** — 본인의 미래 서사
2. **자식의 미래** — 자녀의 미래 서사
3. **과거를 바꿨다면의 미래** — 다른 선택을 했다면 가는 미래

# HARU 독보적 서비스 5가지

> 홍보 시나리오 필수 활용 — 세계 유일 AI 기록 플랫폼

## ① 영어성경
**성경 + AI 영어학습 + 기록**
- KJV 영어성경 + GPT-4o 문법 검증
- 듣기·번역·단어·문법·퀴즈 통합
- 매일 한 절씩 영어 공부 + 신앙 기록

## ② 영어일기
**일상 → AI 교정 + 저장**
- 한글 일기를 영어로 번역
- AI 교정 + 음성 듣기
- 영어 단어·문법 학습 자동 연계

## ③ HARU예언 (구 "나도작가" / Book Studio)
**내 기록 → 책 한 권**
- 사주/관상보다 과학적인 AI 예언
- 내 실제 기록(일기·에세이)에서 미래 서사 생성
- 마케팅 문구: "사주보다 정확한 AI 예언 — HARU예언" / "AI가 당신의 과거 기록으로 미래를 씁니다"

## ④ 하루LAW
**법령 OpenAPI + Gemini RAG + 일상 법률**
- 대한민국 법제처 API 연동
- AI가 법령을 쉽게 풀이
- 판례 추천까지

## ⑤ 기록통계·합본
**데이터 분석 + 합본 PDF**
- 내 기록 통계 시각화
- 전체 기록을 한 권의 PDF로 합본
- 인생을 책으로 남김

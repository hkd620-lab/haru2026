## 3. 잔여 추적 항목

### A-1. 과거 backup/apply/privacy 실행 영수증·원본/캐시 이력

- 상태: **확인 필요** (미실행·실패로 단정하지 않음)
- 현재 사실: PR #203·Slack·알려진 증거 경로에서 당시 실행 영수증을 확보하지 못함. 과거 원본 보존·실행자·캐시 이력은 미확인.
- 해석 제한: 당시 공개 TTL 1년 보고를 현재 익명 403으로 상쇄하거나 전역 캐시 퇴출로 해석하지 않는다. 과거 공개 응답의 캐시 잔존 여부는 미확인으로 유지한다.
- 재개 조건: 당시 산출물 + checksum, 또는 실행 시점 로그를 확보했을 때.
- 금지: backup/apply/privacy 재실행, 객체 삭제, ACL/cache 변경.
- 근거: <https://github.com/hkd620-lab/haru2026/pull/203>

### A-2. 최초 Facebook ZIP 대비 수집 완전성

- 상태: **확인 필요**
- 현재 사실: 현재 참조 누락 0은 저장된 참조가 객체를 가리킨다는 뜻이며, 원본 ZIP의 전체 자료를 수집했다는 증명이 아니다.
- 재개 조건: 최초 ZIP 원본과 대조 근거를 확보했을 때.
- 재개 시 첫 작업: 새 수집·덮어쓰기 없이 **비교 계획부터** 수립한다.

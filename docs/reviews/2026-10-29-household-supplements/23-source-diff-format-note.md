# 검토용 소스 diff 기록 형식 보정

수정 출처는 `git diff --unified=0 14b20616a017ecb608a3375a52f37d4dfcc68058..75f2f0ce24ce2a84d094dc6f11a514cb425ca968 -- frontend/src`이다.

23-review-fix-source.diff의 최초 원문은 기본 unified diff라 문맥의 빈 줄이 단일 공백으로 기록됐다. 추가 파일 자체를 검사한 `git diff --cached --check`가 이를 trailing whitespace로 표시했으나, 기장이 결과를 조건으로 중단하지 않아 `75f2f0ce` 커밋을 진행했다. 소스 변경의 검증 결과와 별개인 기록 검사 실패이며, 이후 조건부 중단을 적용했다.

같은 두 커밋의 소스 변경을 **문맥 0줄** diff로 다시 생성하여 해당 기록 파일을 수정했다. 소스·테스트·원문 검토 판정은 바꾸지 않았다. 변경 전 기록은 75f2f0ce에서 그대로 확인할 수 있다. 이 파일 수정은 '새 검토 파일 추가만' 예외에 해당하지 않으므로, 다음 Codex 및 독립 검토 요청에 원 출처·수정 사실과 이 diff를 명시하고 재검토를 받는다. 이 보정의 diff/check 결과는 해당 커밋에 기록한다.

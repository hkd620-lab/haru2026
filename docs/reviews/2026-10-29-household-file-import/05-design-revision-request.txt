중요: 실제 국민카드 형식이 검증되지 않았으므로 특정 추정헤더를 지원한다고 과장하지 말 것. 안내에 국민카드 공식 MyKB>카드이용>이용내역·매출전표와 로그인후엑셀확인전 명시. 파서는 엄격한 연도포함날짜/가맹점/이용금액/상태 열에 한정한 '카드 이용내역 엑셀 시범 가져오기(아래 필수 열이 있는 양식)'로 명확히 표시하고 어떤 국민카드 파일도 지원 보장하지 않음. 같은 화면에 지원필수열을 보여 주어 항상 거부되는 기능이 되지 않게 함. 실제형식 검증은 추가E2E. 샘플 표준양식다운로드 새기능은 추가하지 않는다.
M2 할부 열이 없으면 할부 여부를 확인할 수 없으므로 파일 읽기 전 사용자에게 '승인 이용내역이며, 청구서/월별 할부 청구 내역이 아님'을 확인받고, 할부 열에 값이 있는데 해석불가면 차단. 구매전체금액기준을 분명히 안내. 불명확한 헤더/행은 파일전체거부, 외화/취소양수는 차단+명시선택 규칙. 새은행 카드대금 후보는 사용자 이체변경만 기존change함수 재사용.
순수저장검증을 서버서비스 변경 없이 UI 두 저장진입(하단 공통저장 포함)에서 우회못하게 한다. 카드필수 확인은 parser row metadata로 유지하고 저장 직전 실제선택행과 대조. blocked amount=''와 선택불가. 카카오 영향 없음. 원문보존 및 API자동연동제외 새장부 작성은 구현때 한다.

## 비차단 주석 (필수조건 아님)

1. **SSR 테스트 문구 해석.** N2 테스트 "5개 은행 영역에 '지원' 문구 0건"은 N1의 상태 표시 "파일 가져오기 미지원"과 글자 단위로 겹칩니다. 그대로 부분 문자열로 검사하면 테스트가 반드시 실패합니다. 구현할 때는 '미지원'을 뺀 긍정 표현('지원'·'읽을 수 있음')만 세도록 해석하면 됩니다. 원래 08 문구에서 생긴 표현 문제이며, 설계를 다시 낼 사유는 아닙니다.
2. **소수 서식 거부가 실제 파일을 막을 수 있음.** N5 규칙에 따르면 숫자 셀의 서식(`z`)에 소수점만 있어도, 예를 들어 `#,##0.00`이어도 파일 전체를 거부합니다. 안전하게 막는 방향이라 오류는 아닙니다. 다만 실제 국민카드 파일이 늘 거부될 수 있습니다. 이 경우 열 이름이나 규칙을 넓히지 말고, 이미 정한 멈춤 조건과 실제 파일 E2E 결과로 보고하면 됩니다.

# 이번 작업 실행 담당 변경

허대표님 현재 대화 직접 지시: `1`, 이어서 선택 답변 `이번 작업은 Codex가 구현`.

질문 원문: CC 월간 지출 한도로 구현이 차단된 상황에서, 이번 파일 가져오기 작업은 Codex가 직접 구현·검증하고 가능한 독립 검토와 PR 리뷰를 거치도록 역할을 변경할지 물었다.

적용: 이번 `codex-household-file-import` 작업은 Codex가 직접 구현·검증·Git을 수행한다. 정책8.1 문서 자체는 수정하지 않는다. 기존 독립 설계 승인11, 수정 후 승인 누적2회, 원문 보존과 승인된 범위를 유지한다. 독립 완료 검토·최신 PR 리뷰·최종 CI 통과를 면제받은 것으로 해석하지 않는다. 해당 게이트가 충족되지 않으면 초안 PR까지 준비하고 병합·배포하지 않는다.

API 자동연동 제외. 안내 대상은 KB국민은행·국민카드·카카오뱅크와 신한·하나·우리·NH농협은행. 타은행 파일 파서 지원 확대는 이번 첫 구현에 포함하지 않는다. 이후 다른 은행 파일 가져오기는 별도 형식 근거를 확인해 이어간다.

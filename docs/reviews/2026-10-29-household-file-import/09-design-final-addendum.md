## N4·N5 금액 판독 우선순위

- 조건(행마다 위에서부터 판정)
  1. 상태나 날짜를 판독할 수 없음 → 파일 전체 거부
  2. 이용금액 칸에 값이 있음
     - 텍스트 셀: 숫자, 쉼표, 앞의 `-`, 괄호, 끝의 `원`만 허용합니다. `$`·`€`·`¥`·`£`·`₩`, 영문 통화코드(`USD` 등), 소수점이 하나라도 있으면 파일 전체 거부
     - 숫자 셀: 값에 소수부가 있거나, 원시 셀의 `z`(서식)나 `w`(표시 문자열)에 원화가 아닌 통화기호나 소수점이 있으면 파일 전체 거부
  3. 이용금액이 비어 있고 현지금액이나 통화 칸에 값이 있음 → 해당 행만 blocked
  4. 이용금액이 비어 있고 외화 근거도 없음 → 파일 전체 거부
  - blocked는 3번(외화로 식별된 행)에만 씁니다.
  - `z`와 `w`를 얻으려면 `XLSX.read(data, { cellNF: true, cellText: true })`로 읽어야 합니다. 이용금액은 `sheet_to_json` 값이 아니라 원시 셀 객체(`sheet[addr]`)의 `t`/`v`/`z`/`w`로 판정합니다.
- 테스트
  - `$12`, `12.50`, `₩1,000`, `USD 12` 텍스트 → 각각 거부
  - `z`가 USD 서식인 숫자 셀 → 거부
  - `w`에 `$`가 있는 숫자 셀 → 거부
  - `(1,000)`, `-1,000원`, `1,000` → 통과
  - 이용금액이 비어 있고 통화가 USD → 그 행만 blocked
  - 이용금액이 비어 있고 외화 근거도 없음 → 거부
  - 날짜를 판독할 수 없음 → 거부
  - 읽기 옵션에 `cellNF:true`·`cellText:true`가 들어감(합성 xlsx로 `z`/`w` 존재 확인)

## N6 사전 확인과 카드종류 고정

- 조건

  - "다시 선택"을 누르면 기관을 바꿀 때와 같이 전부 초기화하고 파일을 다시 읽어야 합니다.

  - "다시 선택"으로 카드종류를 바꾸면 미리보기가 비워짐
  - context와 entry의 결제수단이 다르면 `validateHouseholdImportSave`가 차단

## N7 취소 선택의 순수 검증과 실제 선택 행 대조

- 조건
  - `FormatModal.tsx:3072` 개별 토글과 `:3080` 모두 선택은 이미 저장됨, blocked, needsChoice 미결, `cancelChoice==='exclude'`인 행을 선택하지 않습니다.
  - `cancelChoice`는 전용 처리 함수에서만 바꿉니다.
  - `validateHouseholdImportSave`는 저장 직전의 실제 선택 행 목록을 받아, 각 행과 저장할 entry를 하나씩 대조합니다. 개수와 키가 일치해야 하며, 선택되지 않은 행이 entry에 있으면 차단합니다.
  - needsChoice 행은 `cancelChoice==='negative'`이고 `amount === -|expectedAmount|`일 때만 통과합니다. 그 밖의 조합은 모두 차단합니다.
- 테스트
  - negative인데 금액이 양수 → 차단
  - `exclude`인데 선택됨 → 차단
  - `cancelChoice` 없음 → 차단
  - 선택 목록에 없는 entry가 들어옴 → 차단
  - 모두 선택 뒤에도 needsChoice·blocked·exclude 행은 미선택

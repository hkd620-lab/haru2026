# 다운로드 안내 대상·공식 확인 근거

확인일: 2026-10-29 KST. API 자동연동 제외 결정 유지.

## 허대표님 추가 답변 원문

> 국민은행과 국민카드, 카카오 뱅크
> 국내 5대 다른은행도 다운받는방법 안내주면 좋겠어

우선 대상은 KB국민은행·KB국민카드·카카오뱅크. 5대 은행 안내에 신한·하나·우리·NH농협은행을 추가한다. 이번 답변은 안내 대상 확대이며 해당 기관 모든 파일의 파서 지원이 확인됐다는 뜻이 아니다.

## 공식 근거와 확인 한계

- 카카오뱅크 XLSX: https://m.kakaobank.com/FaqView/view/9413 — 계좌 선택→계좌관리→거래내역→거래내역 다운로드. 기간·받을 이메일 입력. 공식 FAQ 본문 확인.
- 카카오뱅크 PDF: https://blog.kakaobank.com/posts/service-transaction-statement — 전체→고객센터→증명서발급→거래내역서(국문)→PDF/팩스/이메일→기간/조회/신청. 공식 블로그 본문 확인.
- KB국민카드: https://card.kbcard.com/ — 공개 메뉴 My KB→카드이용→이용내역·매출전표 확인. 해당 링크 https://card.kbcard.com/MKB/DVIEW/HMBMCXPRIMYS0007 . 로그인 후 엑셀 저장 버튼·앱 다운로드 절차는 확인 전.
- KB국민은행: https://obank.kbstar.com/quics?page=obank — 개인뱅킹→조회→거래내역 조회 공개 메뉴 확인. 로그인 후 엑셀 저장/인쇄 버튼은 확인 전.
- 하나은행: https://www.kebhana.com/ — 조회→거래내역조회 공개 메뉴 확인. 로그인 후 엑셀 저장/인쇄 버튼은 확인 전.
- 우리은행: https://spot.wooribank.com/ — 개인뱅킹→조회 공개 메뉴 확인. 링크 https://spib.wooribank.com/pib/Dream?withyou=PSINQ0001 는 개인로그인 화면으로 연결됨. 로그인 후 다운로드 화면은 확인 전.
- NH농협은행: https://banking.nonghyup.com/nhbank.html — 실제 브라우저 공개 홈의 ‘거래내역’ 버튼 확인. 클릭 시 로그인 화면으로 연결됨. 로그인 후 다운로드 화면은 확인 전.
- 신한은행: https://bank.shinhan.com/index.jsp — 실제 브라우저 전체메뉴→조회→계좌조회→예금/신탁 확인. 클릭 시 로그인 화면으로 연결됨. 로그인 후 거래내역 다운로드 화면은 확인 전.

위 공개 진입 경로를 기관별로 안내할 수 있다. 로그인 후 미확인 단계는 ‘계좌·기간 조회 후 엑셀 저장/다운로드 제공 여부를 확인해 주세요. 없으면 은행 고객센터에 파일 제공 방법을 문의해 주세요’처럼 사용자에게 확인할 행동으로 제시하고, 검증 완료한 클릭 경로처럼 단정하지 않는다. PDF는 제공이 확인된 카카오만 확정 안내한다. 브라우저 인쇄 PDF를 곧바로 하루 파서가 지원한다고 안내하지 않는다.

원본 거래파일·계정·인증정보를 조회하지 않았다. 은행 로그인도 수행하지 않았다. 외부 자료의 원문을 대량 복제하지 않고 공개 메뉴명과 확인 결과만 기록했다.

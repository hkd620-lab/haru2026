## 이전 검토 지적 재판정 (모두 비차단)
1. **구형 `<dialog>` 미지원** (`epubExportGuide.ts:83-89`)
   - `showModal`을 지원하지 않는 브라우저(iOS 15.4 미만, 오래된 WebView)에서는 오류가 나고 "EPUB 생성 실패" 토스트가 뜹니다. 그 브라우저에서는 이전에 되던 기능이 퇴행합니다.
   - 대신 오류가 화면에 드러나고 데이터 손상이나 정보 노출은 없습니다. 안내창도 DOM에서 지워지므로 다시 시도할 수 있습니다. 해당 브라우저 사용자 비중도 낮습니다.
   - 후속 수정: `typeof dialog.showModal !== 'function'`이면 `window.confirm(안내 문구)`로 대신 묻습니다.
2. **날짜 대체값** (`SayuModal.tsx:1038`)
   - 화면에 기록 모달을 띄우는 곳은 `SayuPage.tsx:5387` 하나이고, 모달을 열 때 `recordDate`를 항상 넣어 줍니다(`:1768`, `:2484`). 그래서 `firestoreId.slice(0, 10)`가 쓰이는 일은 사실상 없습니다.
   - 쓰이더라도 본문은 ID로 정확히 고르므로 섞이지 않습니다. 틀어질 수 있는 것은 EPUB 제목과 파일명뿐입니다.
   - 후속 수정: 서버에서 날짜 형식(`^\d{4}-\d{2}-\d{2}$`)을 검사하거나, 단건이면 `record.date`로 제목·파일명을 만듭니다.
3. **파일명 동시 생성 충돌** (`epubExport.ts:288-295`)
   - 이번 PR에서 생긴 문제가 아니라, 기간 내보내기에도 원래 있던 경로 규칙입니다.
   - 같은 사용자가 같은 날짜·같은 형식의 기록 두 개를 거의 동시에 내보낼 때만 생기고, 본인 파일끼리만 덮어써집니다.
   - 후속 수정: 단건 파일명에 ID 끝 6자리를 붙입니다.
4. **설치 링크 접근성**
   - 스크린리더가 "↗"를 그대로 읽고, 새 창으로 열린다는 안내가 없습니다. 기능에는 영향이 없습니다.
   - 후속 수정: `aria-label="Google Play 북 설치하기(새 창)"`를 붙입니다.

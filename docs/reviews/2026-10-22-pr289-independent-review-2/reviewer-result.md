## 남은 위험 (승인을 막지 않음)

1. **레이아웃은 검증되지 않았습니다.** 테스트는 `src`의 존재와 순서만 봅니다. 5장일 때 아래 항목은 확인된 적이 없습니다.
   - 인쇄 시 페이지 넘김
   - SayuPage의 45mm 높이 제한
   - 합본 인쇄의 120px 높이 제한
   - 사진이 3행(2열×3행)으로 늘어난 뒤 본문과 겹치는지

   데이터 손실이 아니라 보기·인쇄 품질 문제입니다. 허대표님이 배포 후 사진 5장짜리 기록으로 인쇄 미리보기를 한 번 보면 충분합니다.
2. **`maxHeight: 120`을 빌드 도중에 추가했습니다.** `validation.md`가 직접 밝힌 내용입니다. 따라서 최종 SHA의 PR CI 빌드가 이 변경을 처음으로 확인하게 됩니다. 8.1절 판정① 조건 1·2에 따라 최신 HEAD의 CI 통과와 로그 첨부가 필요합니다.
3. **테스트가 소스 문자열 위치에 의존합니다.** `'  const getPreviewContent ='`와 SayuPage의 `{(() => {` 마커로 잘라내므로, 이 부분을 리팩터링하면 테스트가 깨집니다. 깨질 때는 `assert.notEqual`로 알려주니 침묵 실패는 아니지만 유지보수 부담은 있습니다. 합본 쪽 `indexOf`에는 같은 가드가 없습니다.

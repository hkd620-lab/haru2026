## 반영 내역

- 필수 항목: 결과 왼쪽 칸도 직접 입력/예시로 구분한다. `resultInput`을 실제 페이지 계산식으로 추가해 체험 버튼을 누르기 전에는 사용자가 입력한 문장을 준비된 결과와 짝지어 표시하지 않는다. 예시 상태에는 `예시 원문`과 그 원문에 대응하는 정리 예시가 표시된다. 직접 입력으로 체험한 뒤에는 양쪽 칸에 같은 원문을 표시한다. 기본 문장 상태로 건강 탭을 고르면 건강 예시임을 왼쪽에도 표시한다.
- 테스트는 실제 페이지의 계산식뿐 아니라 실제 탭 데이터의 id/short/refined와 defaultInput도 추출한다. 체험 전 7개 탭 상태를 추가해 18/18 통과. 첫 fixture 추출 시 JSX 아이콘까지 실행하려다 시험 도구의 파싱 오류가 발생했으며, 필요한 텍스트 필드만 추출하도록 보완했다. 앱 실행 오류가 아니며 실패 로그도 `/private/tmp/haru-pr357-revision2-sayu-test-harness-failure.log`에 보존.
- 권고 1: 체험 페이지 상단/4주/하단의 감정 분석 자동 생성 약속을 모아보기/작성 현황으로 변경. 준비된 의미·주제·감정 분석임을 상단에 명시. 통계 section은 실제 기능이 기간·형식별 작성 현황임을 설명하고 감정 흐름 패널을 예시로 명시. 활용 목록도 `활용 구상 예시`로 구분. 정적인 설명 예시 데이터를 실제 분석 결과나 현재 통계 기능으로 주장하지 않는다.
- 권고 2: 고정 산책 질문은 `이어 쓰기 질문 예시`로 유지. 탭별 생성 기능은 새로 추가하지 않는다.

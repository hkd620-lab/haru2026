## 시안 변경 요약 (원본 시안 대비)
1. 글자(HaRu2026) 제거 — 홈 화면은 OS가 앱 이름을 아래에 표시
2. 잎맥 단순화(주맥 1 + 곁맥 2, 끝을 가늘게), 줄기 1.5배 굵게, 잎 윤곽 곡선 정리
3. 호박 재설계 — 매끈한 타원 + 떠 있는 줄무늬(수박처럼 보임) → 골이 있는 납작 호박(8골, 꼭지 쪽을 보는 사람 쪽으로 36° 돌려 투영)
4. 열매자루 — 오른쪽 줄기 옆면이 아니라 덩굴이 갈라지는 마디에서 나오도록 수정
5. 유지: 두 잎 배치, U자 덩굴, 꼬리, 호박 방향(꼭지 오른쪽), 색상 #004A28 / #FDFEF7

## 수치 확인
- 좌우 여백 18%, 위아래 21.5%

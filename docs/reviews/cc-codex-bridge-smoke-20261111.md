# CC→Codex 댓글 이벤트 연결 시험

- 목적: GitHub PR 댓글 이벤트가 CC 검토 결과를 Codex 후속 검토 요청으로 전달하는지 확인한다.
- 범위: 이 문서만 변경하며 제품 코드와 운영 설정은 바꾸지 않는다.
- 처분: 시험이 끝나면 병합하지 않고 PR을 닫는다.
- 두 번째 이벤트: 권한 수정 뒤 새 커밋을 푸시해 CC 검토와 후속 전달을 다시 확인한다.
- 세 번째 이벤트: CC의 재검토 댓글 제목을 받도록 수정한 뒤 연결의 전체 경로를 확인한다.
- 네 번째 이벤트: 제한된 사용자 토큰으로 남긴 요청에 Codex가 반응하는지 확인한다.

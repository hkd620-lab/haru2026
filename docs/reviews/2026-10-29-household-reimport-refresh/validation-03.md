# Codex P2: 미리보기 폐기 후 직접 입력 복구
- 원문 지적: https://github.com/hkd620-lab/haru2026/pull/314#discussion_r4408449547.
- 목록 지우기는 진행 중인 재확인 version을 무효화하고, ref/확인중/실패 상태/비교 결과/선택/미리보기 목록을 함께 초기화. 가져오기 오류·진행중에 따른 저장 차단은 활성 미리보기가 있을 때만 적용. 직접 입력 요약과 버튼은 폐기된 가져오기 오류를 표시하지 않음.
- 실제 로컬 브라우저 회귀: 합성 PDF 두 건 미리보기 → 로컬 에뮬레이터 중지 → 재확인 실패 안내와 저장 버튼 비활성 확인 → 목록 지우기 → 실패 안내·재확인 버튼 사라짐, 직접 입력 저장 버튼 활성 확인. 운영 자료와 무관하고 새 거래를 저장하지 않음.
- 더미 설정 npm run build 성공: Vite 41.24s + PWA 생성. 변경 영역 회귀 66개 재실행 결과는 후속 command-results-03.txt 참조. 기존 Rules 실제 SDK 20/20은 직전 기능 검증이며 이 P2는 UI 상태만 변경.
- 기존 원문 change.diff의 헤더 공백 한 줄 예외 유지. 그 외 git diff --check 통과. change-03.diff는 hunk 헤더 함수 문맥만 생략한 검토용 diff.
- 원 사건 정확한 경로 미확정, 운영 저장본·원본 키 수정 없음 제한 유지.

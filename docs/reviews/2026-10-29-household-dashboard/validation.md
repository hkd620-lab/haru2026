## 집계 정의

- 월/연도/양끝 포함 직접 기간/전체 조회. 거래가 있는 월을 통계 표·차트로 표시.
- 수입·지출·이체·미분류 및 카테고리 필터, 거래처/메모/금액/결제수단 등 문자열 검색. 검색·필터는 거래 목록/검색결과 소계에만 적용. 상단·통계·비교는 선택 기간 전체임을 화면에 명시.
- 원부호 유지, 카테고리도 음수 포함 순액. 이체는 건수에 포함하되 수입지출에서 제외. 실제 계좌 잔액 아님.
- 직전 기간: 월은 전월 전체, 연은 전년 전체, 직접 기간은 직전 동일 일수. 전년동기 윤일은 2/28로 맞춤. 직접 비교 기간도 양끝 포함. 전체 조회에서는 비교 대신 기간 선택 안내. 기준 0/음수는 증감률 계산하지 않음. 날짜 범위와 건수를 표시하고 일평균 환산하지 않음을 명시.
- 날짜 보정/날짜 미확인/금액 미확인/빈 메타데이터 문서 제외 건수 표시. 빈 배열/메타데이터만 있는 문서를 가짜 거래로 세지 않음. 날짜 없으면 문서 날짜로 표시만 대체, 월만 있으면 1일로 표시. 저장 원본은 그대로.
- 예산은 현재월 전체 기준에서만 표시. 계정별 로딩/초기화/오래된 응답 차단 및 실패/로그아웃/빈 결과 구분.

## 배포·운영 및 한계

- Hosting만 배포 대상. 실제 계정 데이터의 건수·메모는 배포 후 읽기 전용 확인 예정이며 현재 합성 테스트를 운영 확인이라고 주장하지 않는다.
- 현재 구조의 전체 기록 조회 비용은 기존과 동일(한 번 로드 후 메모리 필터). 추가 AI 호출 없음.
- 최대 50건씩 더 보기. 통계 숫자 표는 좁은 화면에서 가로 스크롤 가능. 연도 선택은 기록이 있는 연도와 현재 연도 제공.
- 실제 은행 자동 분류 정확도 개선·전용 현금 입력 폼·SAYU 검색 개편·AI 질문 범위 확장은 이번 범위에 포함하지 않음.
- 문제 시 이 PR revert 후 Hosting 재배포. 거래/메모를 변경하지 않으므로 데이터 복구 작업은 없음.

## 화면과 데이터

월/연도/기간/전체 → 거래·검색 / 통계 / 기간 비교를 구분한다. 조회 전체 합계와 거래 검색 소계의 범위를 명시한다. 이체는 건수에 포함하되 수입/지출에서 제외하고 음수는 원래 부호를 유지한다. 입력 글자 16px, 모바일 수입/지출 2열+차액 전체폭, 차트와 숫자 표를 함께 제공한다. 빈 카테고리는 조회에서 기타로 표시할 뿐 원본은 수정하지 않는다.

529건 합성 원본의 날짜/금액/유형/메모 동등성·불변, 재가져오기 보존을 검증했다. 실제 운영 거래는 읽기 전용으로만 확인하며 이 코드에 거래 쓰기 경로를 추가하지 않았다. 은행/현금 버튼은 기존 가계부 작성창으로 이동한다.

### 지적 사항
1. **낮음, `source.html` 스타일.** 프로젝트는 Tailwind 4.3.3을 씁니다. 그래서 컴포넌트가 실제로 쓰는 값과 source.html 값이 조금 다릅니다.
   - 보라색: Tailwind 4의 `purple-400/500/600`은 oklch 값입니다 (`oklch(71.4% 0.203 305.504)` 등). source.html은 Tailwind 3의 hex 값(#c084fc, #a855f7, #9333ea)을 썼습니다.
   - 하이라이트 흐림: Tailwind 4의 `blur-sm`은 8px인데 source.html은 4px입니다.
   - 컴포넌트에 있는 `backdrop-blur-sm`이 source.html에는 없습니다.
   - 눈으로 보면 거의 같지만, "그대로 옮김"을 엄밀히 따지면 차이가 있습니다. 다음 버전을 만들 때 맞추면 충분합니다.
   - 그라데이션 색 보간 방식 차이는 확인 못 함.
2. **낮음, 서비스워커 미리 저장 용량.** workbox `globPatterns`에 `png`가 들어 있습니다. 그래서 이 약 200KB 이미지도 PWA를 설치할 때마다 미리 저장됩니다. 기능 문제는 없습니다.
3. **낮음, 테스트 하드코딩.** 테스트는 원본 폴더 이름 `haru2026-share-image-v1`을 고정해서 씁니다. v2로 바꿀 때 PNG 버전과 원본 폴더 버전이 서로 맞는지는 검사하지 않습니다. 또 메타 태그 속성 순서가 바뀌면 "없음"으로 실패하는데, 실패하는 쪽이라 안전합니다.
4. **낮음, 브랜드 인상.** 앱 아이콘, 파비콘, 화면 로고는 호박이고 공유 카드는 포도입니다. 대표님이 Slack에서 직접 승인했고("공유 이미지는 포도송이 로고를 사용"), CLAUDE.md의 "포도 = 기존 서비스 식별 로고" 원칙과도 충돌하지 않습니다.
   - 사이트의 모든 주소가 같은 index.html을 쓰므로, `/welcome`과 `/card`를 뺀 모든 공유 링크에 이 이미지가 붙습니다.
   - 포도알 10개를 "형식 10종"으로 읽을 수 있다는 점은 PR 본문에 이미 적혀 있습니다.
5. **낮음, 공유 카드 관점 (기존부터 있던 상태).** `og:type`, `og:site_name`, `og:locale`이 없습니다. 이번 PR 범위 밖이지만, 카카오 카드를 보완할 때 같이 볼 만합니다.

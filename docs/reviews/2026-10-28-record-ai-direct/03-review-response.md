# 독립 검토 1 반영 내역

대상 원문: [01-independent-result.md](01-independent-result.md). 판정 원문은 수정하지 않는다.

- R1: RecordPage 형식 선택창의 간편·프리미엄 안내 문구를 글·사진 → AI 도움 안내 문구로 교체했다.
- S1: AI 도움 안내에 role=dialog, aria-modal=true, aria-labelledby와 제목 ID를 추가했다. 이번 범위는 대화상자 의미 표시이며 기존 모달 전체의 포커스 제어를 재설계하지 않는다.
- S2: iOS PWA의 새 탭 로그인 유지 및 앱 복귀는 실기기 추가 E2E로 남긴다. 실기기 확인 완료를 주장하지 않는다.
- S3: 방식 선택 제거는 공통 초안 이외의 일반 신규 직접 입력에도 적용되어 항목별 입력 선택이 사라진다. 사용자 요구의 ‘기록 방식 선택은 없애고’를 일반 신규 기록에 일관되게 적용한 범위다. 기존 premium 저장 데이터와 독서사유 책 선택 흐름은 유지된다. 성장기록·작물의 별도 입력은 유지된다.
- S4: 원래의 무변경 입력 객체 비교와 별도로 실제 handlePolishWithMode → handleSaveSayu를 실행하여 onSave로 원문·AI 결과·업로드된 사진 2장·메타데이터·초안 ID가 함께 전달되는 테스트를 추가했다.

## 이전 단계의 격리 브라우저 실행 기록

2026-10-28 이 대화의 실제 CUA 검증 결과다. 운영 Firebase와 AI에는 연결하지 않았다.

1. /?draft → 신규 기록: 간편/프리미엄 선택 없이 AI 도움 안내가 열림. 합성 글 2줄·기존 사진 URL 1장 전달 확인.
2. 모의 사용량 조회 2.5초 동안 64px 포도송이와 대기 안내 표시.
3. 조회 완료 뒤 AI로 다듬기 → 합성 결과 → 저장: 저장 완료 안내 및 ‘저장된 사진 1장’ 확인.
4. /?mobile&draft: 390px iframe에서 안내와 포도송이 표시 확인.
5. /?draft&quota=empty: 남은 횟수 0 및 소진 안내, AI 실행 버튼 없음.
6. /?draft&quota=error: 실패 안내·재시도 버튼 확인, 취소 후 편집창에 기존 글·사진 유지.

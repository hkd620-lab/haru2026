## 발견 및 수정한 문제

무료 합본에서 기간을 고르지 않아도 형식 선택만으로 실행 버튼이 활성화되어, 표시되지 않은 최근 30일 범위로 실행됐다. 모의 브라우저에서 `/merge-viewer` 이동 및 조회 1회로 재현.

- MergePage 기본 선택을 `monthly`, 시작일을 이번 달 1일로 일치시킴.
- 실행 직전 선택 기간의 현재 등급을 확인하여 구독 상태가 바뀐 경우에도 기록 조회 전 중단.
- 보조장부 세무용 날짜 초기화는 기존 최근 30일 유지.
- 수정 후 무료 계정에서 기간 미조작 → 일기 선택 → 실행 결과 범위가 2026-10-01~2026-10-23임을 브라우저 증거로 확인.
- 합본 잠금 버튼의 alert 이후 구독 안내 이동은 IAB 대화상자 제어 시간 초과로 완료 확인 못함. 잠금 표시와 실행 가드 테스트로 대체하며 실기기 확인 대상으로 남김.

## 휴대폰 확인 절차

1. haru2026.com을 새로 열고 현재 계정 등급 확인. 등급별 계정이 준비된 경우에만 위 표대로 통계와 합본 기간 허용/잠금 확인(결제·등급 변경 불필요).
2. 통계에서 허용 기간 → 일기 → 통계로 돌아오기. 기간·날짜·기록 수 유지 확인. 프리미엄은 시작일/종료일을 직접 입력 후 왕복 확인.
3. 합본: 형식 선택 후 이번 달 선택을 확인해 실행. 날짜순/사진/총 기록 수 확인. 특별한 날만 선택하면 표시한 SAYU 기록만 나오는지 확인. 이번 달 기본 선택 수정은 후속 PR 배포 후 확인.
4. 일회용 짧은 글을 먼저 메모 앱에도 복사. 기록 화면에서 입력 → 저장하기 → 일기 → 간편 기록. 네트워크를 끄고 원본 저장. 실패 시 글과 사진이 남는지 확인. 저장 중으로 계속 보이면 화면을 유지하고 네트워크 복구 후 결과를 기다림. 오류가 확정된 경우에만 같은 편집창에서 원본 저장 재시도. 목록에 같은 글이 정확히 1건인지 확인. 다음 글 작성 화면이 비어 있는지 확인. 저장 중 새로고침/앱 강제 종료는 이 검증에 포함하지 않음.
5. 사진 1장을 넣은 새 일기를 정상 저장하고 다시 열어 본문·사진 유지 확인. 키보드가 저장 버튼을 가리는지, 화면 가로 넘침이 있는지 확인.
6. 합본 PDF를 파일 앱에서 열어 글·사진 잘림/빈 페이지/날짜순 확인. EPUB는 휴대폰 전자책 앱에서 열어 목차 이동·사진·한글 표시 확인.
7. 결과 전달: 휴대폰 기종, iOS/Android 버전, Safari/Chrome/PWA, 계정 등급, 실패 단계/오류 문구/중복 건수. 개인정보 없는 화면만 전달.

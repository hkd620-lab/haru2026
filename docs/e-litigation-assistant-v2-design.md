# 전자소송비서 v2 설계 기준

> 작성일: 2026-08-01
> 성격: 수동 MVP 구현 전 기준 문서

## 1. 역할

전자소송비서는 법원 문서와 전자소송 진행 상황을 사용자가 직접 확인하고 기록하도록 돕는 체크리스트형 보조 기능이다. HARU는 사건의 법적 의미, 제출기한, 송달 효력, 승소 가능성, 필요한 법률 조치를 확정하지 않는다.

비서의 역할은 다음에 한정한다.

- 법원 문서 정보를 사건 기록에 연결
- 사용자가 입력한 요구사항과 준비자료를 목록으로 정리
- 사용자가 직접 입력한 기한을 오늘 할 일에 표시
- 사건 상세에서 문서와 처리 상태를 다시 확인할 수 있게 보관

## 2. 금지 범위

다음 기능은 v2 수동 MVP 범위에서 구현하지 않는다.

- OCR, 이미지 업로드, PDF 업로드
- Gemini 또는 기타 AI를 통한 법원 문서 추출
- 법원 문서 원본 저장
- 법정기한 자동 계산
- 송달일, 간주송달일, 제출기한 자동 확정
- 승소 가능성 판단 또는 법률 효과 단정
- 전자소송포털 자동 로그인, 스크래핑, 자동 제출
- 기존 `users/{uid}/records/{date}` 경로 변경

## 3. 이미 구현된 기능

- 전자소송비서 홈: `/legal-assistant`
- 전자소송연습: `/lawsuit-practice`
- 사건 목록: `/legal-cases`
- 사건 상세: `/legal-cases/:caseId`
- 사건 저장 경로: `users/{uid}/legalCases/{caseId}`
- 문서 저장 경로: `users/{uid}/legalCases/{caseId}/documents/{documentId}`
- 오늘 할 일 생성: `legalTodayService`
- 사건 진행지도: `LegalCaseProgressMap`
- 연습 결과를 `practiceDraft`로 사건에 저장
- 청구원인 AI 초안 서버 측 일일 쿼터

## 4. 이번 구현 대상

이번 구현은 "법원에서 문서를 받았어요" 입구를 수동 입력 기반으로 활성화한다.

신규 경로는 `/legal-assistant/document-helper`이며, 사용자는 기존 사건을 선택한 뒤 문서 종류, 법원명, 사건번호, 문서 작성일, 실제 송달받은 날짜, 문서에 적힌 기한 원문, 직접 확인한 제출기한, 법원이 요구한 사항, 준비해야 할 자료, 사용자 메모를 입력한다.

저장 성공 후 사건 상세의 보정·기한 탭으로 이동하고, 기존 문서 목록과 오늘 할 일에 연결되도록 한다.

## 5. 사용자 입력 기한 원칙

오늘 할 일, D-day, 기한 임박 판단은 오직 `dueDateByUserInput`만 사용한다.

`dueDateTextFromDocument`는 법원 문서에 적힌 기한 문구 또는 사용자가 원문에서 옮겨 적은 문장이다. 이 값은 날짜로 자동 변환하지 않고, `dueDateByUserInput`으로 자동 승격하지 않는다.

## 6. 후보값과 확정값 분리

향후 AI 또는 OCR을 추가하더라도 AI가 읽어낸 후보값은 사용자 확정값과 물리적으로 분리한다.

- 후보 또는 원문 기한 문구: `dueDateTextFromDocument`
- 사용자 확정 관리 기한: `dueDateByUserInput`

사용자가 별도 입력 필드에 직접 입력한 날짜만 관리용 제출기한이 된다.

## 7. 원본 문서 비저장 원칙

수동 MVP에서는 법원 문서 이미지, PDF, 원본 파일을 저장하지 않는다. 사용자가 직접 확인한 핵심 메타데이터와 요구사항 목록만 Firestore 문서 기록에 저장한다.

향후 이미지 기반 도우미를 추가하더라도 원본 이미지는 서버나 Storage에 저장하지 않는 방향을 우선한다.

## 8. 내가 할 것 / HARU가 도울 것

화면은 사용자의 책임과 HARU의 보조 범위를 분리해 보여준다.

내가 할 것:

- 법원 문서 원문 확인
- 실제 송달일 확인
- 제출기한 직접 확인
- 요구사항과 첨부서류 확인
- 전자소송 사이트 또는 법원에 직접 제출
- 제출 완료 여부 확인

HARU가 도울 것:

- 문서 정보를 사건에 연결
- 요구사항을 체크 가능한 항목으로 정리
- 준비자료를 목록으로 관리
- 사용자가 입력한 기한을 오늘 할 일에 표시
- 사건 기록에 문서와 진행상황을 보관

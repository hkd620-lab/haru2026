## 향후 별도 승인 후 평가할 때의 수용 계획

1. 평가 전에 현재 모델·질문·파서·정책 버전과 fixture 파일 해시를 고정한다. 한국어 검토자가 정답과 근거를 먼저 검토한다. 이 20개는 작은 개발 표본이므로 조정에 사용한 뒤 독립 검증 표본으로 재사용하지 않는다.
2. 정확한 합성 본문과 고정 질문만 TypeSafe AI에 전송하는 목적·자료·예산·보존 조건 및 필요한 접근 권한을 별도로 승인받아야 한다. 라벨, 근거, fixture ID를 요청에 추가하지 않는다. 이 문서는 키 생성/조회/저장, 서비스 설정, 배포, 실제 사용자 자료 접근을 허용하지 않는다.
3. 승인된 별도 평가에서는 표본당 최대 1회, 총 최대 20회만 수행한다. 오류나 불확실한 과금 결과를 자동 재시도하지 않는다. 실패 건은 분모에서 지우지 않고 invalid/error/unknown으로 보고한다. 응답을 fixture 기대값으로 대체하지 않는다.
4. 기록할 결과는 표본 ID, 모델·정책·프롬프트 버전/해시, 관측된 범주·범위 점수·확률·확신, 파서 결정, 최종 적용 가능 여부, 검증된 사용량과 상태다. 키나 계정 식별자는 저장하지 않는다. 관측 결과와 기대값은 별도 열로 유지한다.
5. 제안하는 개발 표본 통과 기준은 정확한 범주 및 최종 적용 가능 결정 15/15, 검토 기대값의 비적용 5/5, 잘못된 자동 분류 0, 오류·invalid·unknown 0이다. 특히 `clinical-ai`, `ai-medical-dataset`, `invest-ai-stocks`, `invest-medical-stocks`, `daily-ai-appliance`, `mixed-equal`, `out-instruction`은 모두 충족해야 한다. 보수적인 보류도 15개 분류 표본에서는 정확한 자동 분류 성공으로 계산하지 않는다.
6. 현재 파서는 선택 확률 0.85 이상, 분포 확신 0.8 이상 등으로 분류할 수 있지만 저장 runner는 반환 확신 0.85 이상도 요구한다. 따라서 파서의 `classified`만 세지 말고 최종 runner 기준까지 만족한 경우에만 적용 가능 성공으로 센다. 임계값을 낮춰 표본을 통과시키지 않는다.
7. 분류 기대 15개의 정확 일치율과 검토 기대 5개의 보류율, 범주별 결과, 잘못된 자동 분류 수, 오류 수를 모두 보고한다. 검토의 세부 원인은 확률에 의존하므로 표본 정답은 특정 review reason을 강제하지 않는다. 통과하더라도 한국어 실자료 정확도·확률 보정·운영 안전성이 검증되었다고 주장하지 않는다. 실제 자료 시험이나 운영 활성화는 별도 범위다.

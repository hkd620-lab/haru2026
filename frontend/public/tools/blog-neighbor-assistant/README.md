# 블로그 이웃관리 보조도구

네이버 블로그 이웃추가를 자동 실행하지 않고, 사용자가 직접 입력한 후보와 메모를 로컬에서 관리하는 정적 도구입니다.

## 기능

- 사용자가 직접 입력한 네이버 블로그 주소, 표시 이름, 관심사, 메모 저장
- 후보 상태 관리: 후보, 방문함, 신청함, 답변옴, 보류, 제외
- 신청 멘트 초안 생성 및 직접 수정
- 멘트 복사
- 네이버 블로그 페이지 새 탭 열기
- 사용자가 네이버 화면에서 직접 신청한 뒤 `수동 신청 기록` 저장

## 하지 않는 일

- 네이버 이웃추가 버튼 자동 클릭
- 서로이웃 신청 자동 발송
- 네이버 ID 자동 수집
- 게시물 자동 스크래핑
- 네이버 DOM 조작
- 캡차 우회
- IP 변경 또는 랜덤 딜레이 기반 반복 실행

## 실행

브라우저에서 `index.html`을 열면 바로 사용할 수 있습니다. 데이터는 현재 브라우저의 `localStorage`에 저장됩니다.

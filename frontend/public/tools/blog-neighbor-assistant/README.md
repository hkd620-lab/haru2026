# 블로그 이웃관리 보조도구 v2

HARU2026 블로그 홍보를 위해 **직접 방문한** 네이버 블로그 후보를 관리하는 수동 CRM 도구입니다.

## 기능 요약

### 후보 관리
- 네이버 블로그 주소(`blog.naver.com`, `m.blog.naver.com`) 입력 및 유효성 검사
- 표시 이름, 관심분야, 관심도, 마지막/다음 방문일, 댓글 여부, HARU 안내 현황, 메모 저장
- 상태 6단계: 후보 → 방문함 → 신청함 → 답변옴 → 보류 → 제외

### 필드 목록
| 필드 | 값 |
|------|-----|
| 관심분야 | AI / 일기·기록 / 중장년 / 건강관리 / 교육 / 은퇴생활 / 블로그마케팅 / 기타 |
| 관심도 | 낮음 / 보통 / 높음 / 매우높음 |
| 댓글 여부 | 안함 / 댓글남김 / 답글받음 |
| HARU 안내 여부 | 미안내 / 간단소개 / 체험링크전달 / 관심보임 / 거절·무반응 |

### 통계 (7개)
전체 · 신청함 · 답변옴 · 관심도 높음↑ · 오늘 방문 · 방문일 지남 · HARU 링크전달

### 필터 (4종)
- 상태 / 관심분야 / 관심도 / 방문일(오늘 · 지남 · 이번 주)

### 이웃신청 멘트
- 관심분야별 초안 자동 생성 (저장 시점에 1회 생성, 이후 직접 편집 가능)
- 멘트 복사 버튼으로 클립보드에 복사

### 수동 신청 기록
- "수동 신청 기록" 버튼 클릭 → 상태 "신청함" 변경 + 마지막 방문일 자동 기록 + 메모에 타임스탬프 추가

### CSV 백업
- **내보내기**: 현재 목록 전체를 CSV로 저장 (Excel에서 열 수 있도록 BOM 포함)
- **가져오기**: 기존 CSV 불러오기 — 기존 목록에 추가 또는 전체 교체 선택 가능
- URL 유효성 검사: 잘못된 주소는 건너뛰고 오류 건수 표시
- CSV 컬럼: `blogName`, `blogUrl`, `category`, `status`, `interestLevel`, `commentStatus`, `haruIntroStatus`, `lastVisitedAt`, `nextVisitAt`, `memo`, `message`, `createdAt`, `updatedAt`

### 기존 데이터 호환
이전 버전(v1) 데이터를 자동으로 불러오고, 없는 필드에 기본값을 적용합니다.

---

## 이 도구가 하지 않는 것

- 자동 이웃신청, 자동 클릭, 자동화된 일괄 처리
- 네이버 블로그 크롤링 또는 스크래핑
- 캡차 우회, DOM 조작
- 서버 통신, 외부 API 호출
- 로그인 대행

모든 방문, 댓글, 신청 행위는 **사용자가 직접** 수행해야 합니다.

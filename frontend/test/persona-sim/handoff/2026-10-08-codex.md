### 3-5. 산출물과 커밋 방법

  ```bash
  git worktree add -B claude/elegant-noether-z5zy29 /private/tmp/haru-persona-dev origin/claude/elegant-noether-z5zy29
  # 새 personas/*.mjs, reports/<이름>/ 등만 복사한 뒤

  git diff --cached --name-only     # frontend/test/persona-sim/ 밖 파일이 없어야 함
  git commit -m "test(persona-sim): ..."
  git push origin claude/elegant-noether-z5zy29
  ```

  `--force` · `--no-verify` 금지. push가 거부되면(non-fast-forward) 중단하고 보고합니다. 이 브랜치는 `main`에 병합하지 않습니다.

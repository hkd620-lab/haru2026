Chrome 확장 프로그램 저장 위치, 허 교장님!
확장 프로그램이 "로컬 저장"할 때 위치

실제 하드 파일로 저장되는 게 아니라 Chrome 내부 저장소에 저장됩니다!

저장 방식	실제 위치
chrome.storage.local	Chrome 프로필 폴더 내부
IndexedDB	Chrome 캐시 내부
일반 파일(다운로드)	Mac: ~/Downloads/
Mac 기준 Chrome 내부 저장 경로
~/Library/Application Support/Google/Chrome/Default/Local Extension Settings/

일반인이 직접 열어보기 어려운 구조입니다.
